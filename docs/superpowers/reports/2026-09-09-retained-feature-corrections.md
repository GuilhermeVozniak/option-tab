# Retained feature corrections

The roadmap audit after `1ad6e40` found missing behavior as well as incomplete native acceptance. This batch adds native-Dock preview middle-click and unpinned-app relaunch, fixes replacement-Dock interaction holds, and completes additional control and built-in metadata translations. It removes unsafe switcher mouse/wheel action fallbacks. It does not publish a release or reintroduce features owned by sibling products.

## Corrected behavior

- **Dock preview middle-click:** Preferences → Dock exposes an independent preview middle-click action, defaulting to None. A middle-button press acts once on the clicked preview through the existing exact session/window/application admission. It neither focuses the preview nor begins dragging. The trailing auxiliary-click event cannot dispatch a second action. Invalid imported policies are refused or normalized safely.
- **Switcher input qualification:** The previous “two-finger swipe” handlers actually accepted primary mouse drags and ordinary DOM wheel events, which could close or minimize windows unintentionally. Both paths are removed. Saved swipe choices remain visible but disabled with an explanation. A qualified native switcher trackpad route is still missing; this is a corrected availability boundary, not completed B08.
- **Unpinned app Relaunch:** Every eligible running application can expose Relaunch in its replacement-Dock context menu. Running-only targets capture temporary authority from the exact current PID/start identity, bundle URL and filesystem resource. Pins retain their private-reference checks. Both paths preserve graceful exit, native panel ownership, cancellation, manager drains and refusal to substitute a successor application. A save veto or timeout does not force termination. If the parent retires after termination was already delivered, reopening is refused; the completed termination cannot be rolled back.
- **Auto-hide during interaction:** Owned clicks, reordering and open item/group menus now hold an already-visible Dock. A two-second native lease expires without renewals; frontend requests have one in-flight operation and one coalesced latest state. Explicit begin/renew/end phases distinguish fresh input from delayed callbacks. Fresh interactions can acquire updated items in the same visible session, while old renewals cannot adopt changed items, geometry, profiles or processes. Pointer release, cancellation, lost capture, Escape, blur, menu dismissal and retirement release ownership. Native Dock recovery, unavailable environment and suspension take priority over the hold. Lost pointer capture also cancels the reorder draft itself.
- **Localization:** Additional PT-BR and Spanish labels cover visible controls and accessible names. Source AST inventory checks literal translation calls and conditional branches, alongside the prior dynamic-key coverage. Built-in Clock, Battery, Network and Audio metadata, including Clock setting names, is localized only in presentation copies after exact built-in digest verification. Immutable manifests, grants and community/user literals remain unchanged. Raw provider category/boolean readings and dynamically computed strings outside these checks retain a separate localization audit boundary.

## Verification

Independent review covered input admission, localization/package authority, native relaunch lifetime and auto-hide ownership. Auto-hide review reproduced a same-session fresh-input refusal; regression tests failed before the phase correction and pass afterward. Separate regressions reproduced queued-begin replacement and reorder dispatch after lost pointer capture; both were corrected.

Final checks passed: **503 desktop, seven shared and four website unit tests**; all **25 Go packages** with race detection and coverage, with the complete App and launcher packages rerun after the phase correction; **113 Chromium tests and ten WebKit layout tests**, two workers and no retries; TypeScript, full Biome and golangci-lint (zero issues). The initial browser run exposed missing test RPC registration and stale fixture bounds; the corrected full runs passed. On September 15, a resume audit confirmed all 819 recorded source hashes, every pending source file and all eight browser-specific hashes still matched the passing evidence. No suite rerun was needed for unchanged source.

Published downloads and the cask remain on v0.4.8 until an explicitly requested, verified public release.
