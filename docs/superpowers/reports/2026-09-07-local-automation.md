# Local automation implementation checkpoint

Scope: retained F01–F06, following the media checkpoint at `4f0c150`. The feature branch now contains the local AppleScript transport, typed commands, independent app-preview presentation and optional cached-image queries. Native end-to-end acceptance remains incomplete; this is not a release.

## Available behavior

- The packaged `OptionTab.sdef` exposes seven commands: open switcher, show/hide app previews, perform a window action, query applications, query windows and query the active window. [Terminal and macro-tool documentation](../../automation.md) describes selectors, JSON, errors and limits. Its escaped AppleScript examples compile against a dictionary-only bundle without executing actions.
- App name, bundle ID and PID selectors match exactly and refuse ambiguity. Actions retain process launch and window identity through preparation and final dispatch. Active-window resolution requires an exact Accessibility focused root. Minimize and fullscreen set explicit states; focus, close and application hide use guarded native operations.
- Opening an already open switcher preserves selection and session. Automation previews have an independent owner, capture peer, route and nonactivating native host. Omitted coordinates choose the current display with a main-display fallback; explicit global logical coordinates choose and clamp to a real display, including negative origins. Late hide, frame, action or host callbacks cannot affect a replacement owner or native Dock hover.
- Queries do not activate apps, request consent or initiate capture. Optional images copy existing identity-tagged PNG cache entries, with a 30-second age limit, eight-image limit and 512 KiB encoded per image. Equal identities from two presentation owners coalesce to the newest capture; conflicting identities refuse export. Replies are capped at 500 inventory entries and 4 MiB, with explicit omission information.
- Apple-event receipt, descriptor ownership and suspended replies remain native-owned. Work leaves AppKit before Go/AX processing. The private suite preserves standard Wails handlers. Sixteen pending requests, bounded input and a five-second receipt deadline constrain admission; shutdown cancels work and drains each suspended reply once on main without joining workers there.
- Existing and automation captures share four stream slots and one snapshot slot, with two live priorities per owner. Live fallback also respects the snapshot limit. Independent observers of the same window preserve positive destruction evidence when one peer finishes. Cached image export performs no AX lookup from a capture callback.

## Verification

Independent reviews covered transport/reference lifetime, exact request retirement, active-window actions, capture/cache ownership and preview session admission. Confirmed regressions were fixed: busy reply cleanup waiting on a contended mutex, restarting the receipt budget during worker admission, derived contexts losing the exact native cancellation guard, shared snapshot fallback bypassing its limit, one peer invalidating another's destruction observer, selected window 31 starving behind a full frame cache, and default preview placement ignoring the current display.

The final combined gate passes 20 Go packages with race detection and coverage, 272 desktop frontend tests plus five shared and three site tests, and 64 desktop Chromium checks. Biome and Go lint pass. Generated Wails bindings contain 74 methods and 33 models, with zero generator warnings using the pinned CLI. Production frontend and embedded native binary builds pass; plist/XML and bundle-script syntax checks pass. Existing SDK deployment-target/deprecation warnings remain a distribution compatibility follow-up, not evidence of older-macOS support.

Native fixtures exercise production descriptor decoding, exact action preparation/identity checks and reply ownership with controlled dependencies. The transport fixture finishes with 20 suspended and 20 resumed replies. A real self-process event reached the handler and was refused under the direct-call provenance rule. A separate ad-hoc signed, windowless LaunchServices bundle exposed all seven dictionary commands and registered successfully. Its no-prompt cross-process preflight returned `errAEEventWouldRequireUserConsent` (-1744); no event was sent after refusal. Exact fixture processes and temporary bundles were cleaned up.

## Remaining acceptance

F01–F06 remain unchecked until real `osascript` round trips, returned query/image JSON, packaged Wails preview rendering/actions and fixture-only native action postconditions are established with the required macOS authorization. Browser transport tests and substituted native fixtures do not prove physical controls, permission transitions, Retina/disconnect handling or other-Space focus.

No consent prompt, real-user window action, player operation or Dock/cursor movement was performed for this checkpoint. The earlier unanswered Dock restoration question remains separate. A native operation already dispatched cannot be recalled after timeout; queries and fresh identities should precede a mutation retry. Numeric window reuse within one process lifetime and the public NSAppleEventManager handler-target introspection limit are documented in the implementation evidence.

Reproducible native fixture sources remain under `apps/desktop/internal/platform/testdata/automation-transport/` and `automation-active/`. Session reports and red/green logs are preserved in the ignored `.superpowers/sdd/2026-09-07-local-automation/` directory (frontend/switcher reports use the adjacent `2026-09-06-local-automation/` directory). Combined logs are `/tmp/option-tab-automation-{go,unit,browser,biome,golangci,native}-final.log`.
